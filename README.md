# Random Art Generator

**Project type:** Frontend (HTML + CSS + JS)  
**Course:** Version Control Systems — Git Bash & GitHub Hands-On Project.

## Project Summary
A small generative art web app that produces unique artwork from a numeric seed and user-selected palettes. Designed to be reproducible (seeded) and provide many opportunities for branching, conflicts, and documentation required by the assignment.

## Run locally (commands)
1. Clone (after you create remote repo):
```bash
git clone <your-repo-url>
cd random-art-generator
```
2. Open `index.html` in a browser:
```bash
# Linux:
xdg-open index.html
# macOS:
open index.html
# Windows:
start index.html
```

## Suggested Git workflow (example)
- `git init`, make 10+ commits with clear messages.
- Create at least 4 branches (feature, bugfix, experiment, etc.).
- Demonstrate a merge conflict by editing the same line in two branches then merging.
- Add README, screenshots in `assets/`, and push to GitHub.
